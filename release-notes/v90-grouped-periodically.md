# v90 – Grouped periodically

<div align="left"><figure><img src="../.gitbook/assets/image (29).png" alt="" width="285"><figcaption></figcaption></figure></div>

## Features

* Added support for generic and fully-nested widget grouping using the [dynamic group](../app-builder/build-frontend/widgets/dynamic-group.md) widget.
* Enabled high-level data binding for widget groups in the [dynamic group](../app-builder/build-frontend/widgets/dynamic-group.md#data-settings-data-bindings) configuration.
* Added the new [card](../app-builder/build-frontend/widgets/display-widgets/card.md) widget.
* Improved the [status lamp](../app-builder/build-frontend/widgets/display-widgets/status-lamp.md) widget to support multiple states and a rectangular shape.
* Improved the icon component in [Text, icons and images](../app-builder/build-frontend/text-icons-and-images.md) to support optional background shapes.
* Added support for configuring multiple new properties at runtime across various [widgets](../app-builder/build-frontend/widgets.md).
* Added database audit logging to the [relational database](../app-builder/build-backend/functions/storage/relational-database.md) connector.
* Added the machine simulator option to the [Process Simulations](../app-builder/build-backend/functions/extensions/process-simulations.md) extension.
* Released the first experimental version of the AI assistant.
* Released the first experimental support for [subflows](../app-builder/build-backend/functions/subflows.md).

## Fixes

* Improved multiple user interface interactions and optimized performance across the workspace.
* Fixed system start behaviors to reliably restore [on-premise installations](../tutorials/on-premise-installation.md) after a power cycle.
* Cleaned up and consolidated the internal widget rendering factory.
