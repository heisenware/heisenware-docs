# Functions

Functions are the building blocks of your logic. They come in classes, such as the OPC UA client or the counter, and agents offer them: the internal agents of the platform, or the agents you install in your own network. Drag a function from the Functions explorer onto the Flowboard and it becomes an executor; [Executors and instances](../../concepts/executors-and-instances.md) explains the model.

* [Connectors](connectors/README.md): talk to machines, protocols and business systems.
* [Storage](storage/README.md): relational and timeseries databases, and in-memory stores.
* [Utilities](utilities/README.md): timers, counters, PDF, simulation and more.
* [Add-ons](add-ons/README.md): extra classes that run in a container of their own.
