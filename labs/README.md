# How the labs work

A lab teaches one real task end to end: you build a small App, or connect one real thing, and keep the result. Each lab says what you build and what you need before you start, and links to the reference for every function and widget it uses.

Labs assume you have built something before. If this is your first App, start with [Your first App with the assistant](../getting-started/first-app-with-the-assistant.md).

* [CRUD with the data grid](crud-with-the-data-grid.md): a table of the workspace's database that users read, edit, extend and clear from the App, with a toast on every write.
* [Automating PDF reports](automating-pdf-reports.md): a form and a signature become a filled PDF that leaves as an email attachment.
* [Photos from the App to a server](photos-to-a-server.md): photos taken on a phone, kept in the workspace's file store, and handed on to an HTTP endpoint or to a folder on your own computer.
* [Connect an external MQTT client](connect-an-external-mqtt-client.md): credentials, topics and both directions between your own MQTT client and the workspace.
* [Connect an Arduino via MQTT](connect-an-arduino-via-mqtt.md): the same, with working ESP32 code to publish from.
* [Connect a Heidenhain CNC via OPC UA](connect-a-heidenhain-cnc.md): the certificate exchange on the control, step by step, and the first live values off the machine.
