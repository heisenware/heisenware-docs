# Iframe

The iframe widget embeds external websites or web applications directly into your Apps. It displays the external web content live within a frame container in your UI.

## Configuration

Set the widget's defaults in the settings panel.

### General settings

| **Property** | **Label** | **Description** | **Type** |
| :--- | :--- | :--- | :--- |
| `src` | URL | The URL of the external website or web page to embed. Must use a valid `http:` or `https:` protocol. | string |
| `showBorder` | Show border | Displays a thin border around the iframe container frame when checked. | boolean |
| `height` | Height | Sets the vertical height of the frame, supporting CSS layout units like percentage or pixels. Defaults to `100%`. | string |
